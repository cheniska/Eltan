# HTML-карта путей и концовок

[Автономный HTML](ending-map.html). Скачайте и откройте файл в браузере: GitHub показывает исходный HTML, а не исполняет его в просмотре файла. Публикация через Pages этим изменением не включалась.

145 узлов и 187 связей: 14 ванильных экранов отставки EndGame(5–18), 2 узла гибели QMM, 16 экранов ShuKlissan, 15 узлов исходов/вариантов Союза. Это не 47 независимых состояний мира: некоторые узлы — варианты и переходные развязки.

Разделы: обзор, ваниль, ShuKlissan за Коалицию и за Клан, начало Союза, политика, Сирота, открытая война. Поиск по всем узлам, масштабирование, перетаскивание, подсветка предшествующих условий, реестр финалов и карточки со состоянием при завершении и будущим эпилогом. Одна текущая сторона игрока. Фокус стороны лишь выделяет узлы, не является полноценным исполнителем скриптов или проверкой доступности.

Основа: [предоставленный аутлайн](sources/ENDING_OUTLINE_PC_FINAL_SHUKLISSAN.md). Содержимое исходных файлов диска E: не было доступно для независимой повторной проверки; их переходы представлены по аутлайну. Сценарий Союза взят из актуальных статей этого репозитория.

Аутлайн уточняет прежний вывод по одному лангу: ветки пиратского руководства при живой Коалиции существуют, а ShuKlissan содержит явный исход за Клан при живой Коалиции и побеждённых доминаторах. Исходная пятёрка — область базовой таблицы, не запрет этих дополнительных маршрутов.

Сирота, союзная махпелла ShuKlissan и подчинённая махпелла Алакая — разные сущности. Бесплатное открытие последнего зова из-за модовой дружбы с махпеллой не добавлялось. Адаптер состояний модов, фракции управляемых клисан и хуки составного эпилога требуют реализации; граф явно отмечает эту границу. Существующие скрипты не изменены.

Проверки: уникальность идентификаторов, целостность 187 связей, все восемь раскладок без перекрытия карточек, логика карточек/поиска/подсветки/реестра/источников в DOM-стенде. Браузерный рендер не проверен: доступный Chromium не запускается из-за ограничения среды на системные сокеты. Адаптивная вёрстка и управление касаниями реализованы, визуальная проверка в настоящем браузере остаётся необходимой.

## Дополнительный большой граф

[Большой единый HTML-граф](ending-map-full.html) добавлен отдельно; прежняя карта сохранена. Все 145 узлов и 199 переходов показаны на общем полотне. Есть подписи решений на стрелках, поиск, масштабирование, перетаскивание, подсветка предшествующих путей и кнопка «Вписать путь». Подсветка объединяет альтернативные маршруты к выбранному узлу, а не требует выполнить их все. Дополнительные связи между сюжетами обозначают условные точки входа и переходы после отказа от отставки.

Проверены общая и восемь частных раскладок без наложения карточек, поиск, карточки, подсветка, вписывание пути и переключение подписей в DOM-стенде. Ограничение браузерной визуальной проверки, указанное выше, сохраняется.
