# Документация «Детей Эльтан»

## Три уровня

| Раздел | Что содержит | Основная статья |
|---|---|---|
| Лор | История, биология, общество, технологии и сведения, истинные до вмешательства игрока | [Лор](lore/Lore.md) |
| Сюжет | События кампании, мотивы, раскрытие сведений, последствия и тексты развязок | [Сюжет](story/Story.md) |
| Геймплей | Допуски, ранги, отношения, задания, показатели, военные правила и условия исходов | [Геймплей](gameplay/Gameplay.md) |

Изменение механики не переписывает автоматически историю мира. Новое сюжетное событие не становится общей способностью технологии. Основания ванили и авторские допущения отмечаются в тексте. Числовые значения и техническая реализация остаются предварительными там, где это уже указано.
